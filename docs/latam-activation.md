# 남미 글로벌 데이터 최초 확인

브라질·아르헨티나·칠레 국가를 글로벌 수요에 추가한 뒤 기존 수집 워크플로를 1회 실행하여 BR Amazon Beauty 카테고리와 국가별 Google Trends를 검증합니다.

- 브라질의 Scrape.do 반환값이 검증되기 전에는 Top 100 수치를 생성하지 않습니다.
- 아르헨티나·칠레에는 독립 Amazon 마켓이 없으므로 순위를 계산하지 않습니다.
- API 비용은 기존 Scrape.do 900크레딧/월, API.SH 750크레딧/월 보호 한도를 적용합니다.
- 현지 뉴스는 무료 Google News RSS이고 원문 제목 기반 한국어 요약임을 명시합니다.
