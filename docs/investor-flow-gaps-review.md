- pykrx 상세/기본 투자자와 공매도 조회는 ValueError, 직접 KRX 조회 복구 여부 미확인.

## 우선 개선

1. 현재일 평가는 보류하되 마지막 공통 거래일의 별도 참고분석을 표시한다. '수급11/10 기준, 현재 주가11/11, 1거래일 차이'를 함께 표시한다. 하루 차이를 숨기거나 이전 수급을 오늘 자료로 복사하지 않는다.
2. 5/20/60일 순매수는 확보된 주수를 우선 표시하고, 원화 환산은 '종가 환산 추정'으로 보조 표기한다.
3. 수급·공매도 거래·공매도 순보유잔고·대차를 독립 카드로 두고 결측 이유 및 마지막 성공시각을 표시한다. 결측 때문에 정상 대차까지 숨기지 않는다.
4. 수급 정상 상태와 마지막 관측 날짜의 완결성을 구분한다. 특정 기간 중간 날짜가 빠졌다면 임의로 건너뛰거나 거래일20개가 있다고 완전기간으로 판정하지 않는다.

## 데이터 경로

### 공매도 거래 및 투자자 세부 내역

한국투자 공식 open-trading-api에는 `daily-short-sale`(FHPST04830000) 및 `investor-trade-by-stock-daily`(FHPTJ04160001)가 있다. 후자는 개인/외국인/기관의 순매수 수량·대금과 `fund_ntby_qty`, `fund_ntby_tr_pbmn`(기금)을 제공한다. KRX/NXT/통합 시장 코드가 구분된다. 실제 계정 호출, 금액 단위, '기금'과 KRX '연기금 등' 분류 대응은 연결 후 원문 대조 필요. 현재 KIS 공매도 구현은 체결 수량/비중만 받고 순보유잔고는 제공하지 않는다.

- https://github.com/koreainvestment/open-trading-api/tree/3a9be59a3ed8745720dc3aa9d584bdf3b7830362/examples_llm/domestic_stock/investor_trade_by_stock_daily
- https://github.com/koreainvestment/open-trading-api/tree/3a9be59a3ed8745720dc3aa9d584bdf3b7830362/examples_llm/domestic_stock/daily_short_sale
- https://apiportal.koreainvestment.com/provider-info

개인 API 접근 가능과 공개 사이트 재배포 허용은 다르다. 공식 제휴 안내에 시세정보 이용계약 제한이 있으므로 키 설정만으로 공개 재배포까지 승인된다고 가정하지 않는다. 주식 계좌나 새로운 약관 수락은 사용자 영역이다.

### 기존 키움 경로

`ka10059` 일별 투자자, `ka10014` 공매도 추이 어댑터가 이미 있다. 공식 안내는 허용IP 인증 및 최대10개 등록을 명시한다. GitHub-hosted runner의 동적IP를 임의 허용하거나 IP제한을 우회하지 않는다. 사용자 승인 고정 송신IP 환경 또는 등록된 집PC에서 읽기전용 수집을 실행하는 경로가 있으나 가동/갱신·보안·공개 데이터 이용권을 먼저 확인해야 한다. 집PC가 켜져 있다는 것만으로 등록IP 일치를 보장하지 않는다.

- https://openapi.kiwoom.com/intro/serviceInfo
- https://openapi.kiwoom.com/m/guide/apiguide

### 잔고 및 무료 공공데이터

금융위 주식대차15059612는 현재 정상. T-1 자료가 다음 영업일13시 이후 제공되는 지연을 유지 표시한다. 이 API로 공매도 순보유잔고를 채우지 않는다. 확인한 공공데이터에서 대차와 동등하게 연결할 공매도·연기금 일별 무료 API는 찾지 못했다(부재의 확정은 아님).

공매도 순보유잔고는 KRX 공식 통계에서 별도 확인해야 한다. 직접 데이터 접속이 안 되면 사용자 다운로드 CSV의 단위·종목·시장·기준일·출처를 검증해 들이는 방법은 가능하지만 자동화는 아니다. 공개 재배포 이용조건도 따로 적용된다.

- https://www.data.go.kr/data/15059612/openapi.do
- https://data.krx.co.kr/contents/MDC/STAT/srt/MDCSTAT300.jsp
