# 남미 Google Trends 신규 국가 초기 데이터

정기 작업이 완료된 당일에도 브라질·아르헨티나의 첫 관측치가 비어 있는 것을 방지하도록 `optional_free_api.py`에 누락 국가 보충 수집을 추가했습니다.

- 이번 갱신은 저장된 기존 국가를 다시 조회하지 않고 누락된 BR/AR에 한정합니다.
- 동일 국가를 하루 여러 번 호출하지 않도록 예약 상태를 저장합니다.
- Amazon BSR은 기존 수집일에 이미 관측된 경우 재사용합니다.
- 무료 API.SH 750크레딧 및 Scrape.do 900크레딧 상한 유지.
